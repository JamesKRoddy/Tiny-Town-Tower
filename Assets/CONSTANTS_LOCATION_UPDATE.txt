================================================================================
                              HOW TO USE
================================================================================

EXAMPLE USAGE:

// Footstep events
string leftFoot = GameConstants.AnimationEvents.FootstepLeft;
string rightFoot = GameConstants.AnimationEvents.FootstepRight;

// Combat events
string attackVfx = GameConstants.AnimationEvents.AttackVFX;
string useWeapon = GameConstants.AnimationEvents.UseWeapon;
string stopWeapon = GameConstants.AnimationEvents.StopWeapon;

// Attack directions
int horizontalLeft = GameConstants.AnimationEvents.AttackDirection.HorizontalLeft;
int verticalDown = GameConstants.AnimationEvents.AttackDirection.VerticalDown;

// Utility methods
if (GameConstants.AnimationEvents.IsFootstepEvent(eventName))
{
    // Handle footstep
}

if (GameConstants.AnimationEvents.IsCombatEvent(eventName))
{
    // Handle combat
}

// Get all event names
string[] allFootsteps = GameConstants.AnimationEvents.GetFootstepEventNames();
string[] allCombat = GameConstants.AnimationEvents.GetCombatEventNames();
string[] allEvents = GameConstants.AnimationEvents.GetAllEventNames();

                              WHAT CHANGED
================================================================================

BEFORE:
-------
Constants were in: Assets/Scripts/Constants/AnimationEventNames.cs
Usage: AnimationEventNames.FOOTSTEP_LEFT

AFTER:
------
Constants are in: Assets/Scripts/Utils/GameConstants.cs
Usage: GameConstants.AnimationEvents.FootstepLeft

CHANGES:
--------
1. Moved from AnimationEventNames to GameConstants.AnimationEvents
2. Naming convention changed to PascalCase (FootstepLeft vs FOOTSTEP_LEFT)
3. Attack directions now nested: GameConstants.AnimationEvents.AttackDirection
4. All utility methods preserved (IsFootstepEvent, GetAllEventNames, etc.)
5. Follows your existing GameConstants pattern

================================================================================
                              INTELLISENSE SUPPORT
================================================================================

With everything in GameConstants, you get better IntelliSense:

Type: GameConstants.
  → Shows all constant categories (Tags, Layers, AnimatorParams, etc.)

Type: GameConstants.AnimationEvents.
  → Shows all animation events (FootstepLeft, AttackVFX, etc.)

Type: GameConstants.AnimationEvents.AttackDirection.
  → Shows all attack directions (HorizontalLeft, VerticalDown, etc.)

Type: GameConstants.AnimationEvents.Is
  → Shows helper methods (IsFootstepEvent, IsCombatEvent, etc.)
